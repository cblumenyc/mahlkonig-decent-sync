# Mahlkönig - Decent sync

Community beta for one Decent and one Mahlkönig E64 WS, with a local Linux server and one active Classic or Decaid v0.9.0 plugin.

- Unified naming, authentic locally bundled artwork and compact status/target/result interfaces.
- Durable controller events, installation identity, HTTP/WebSocket transport and native grinder verification.
- Disabled initial feedback, guided setup, profile commissioning and target readback.
- Reproducible server, Classic, Decaid and Linux Compose packages; verified provenance and code-only rollback.
- Assisted Classic rename with preserved settings, exact queued bytes and recovery material.

Use the installation, compatibility and acceptance documents for the tested combinations and limits. Tablet hosting, other grinders, simultaneous controllers and Home Assistant are outside this beta. Software is GPL-3.0-or-later; logo terms are separate. Independent community project.
